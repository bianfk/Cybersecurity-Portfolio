# Defending Azure - TryHackMe

Notes and progress for the Defending Azure path. 

Coming from a 10+ year IT background, cloud security is pretty new to me. I'm using this path to get hands-on with Microsoft's security tools since a lot of SOC roles seem to focus on them now.

## Modules

- **MS Sentinel:** Intro, deploying, ingesting data, detecting, and investigating.
- **KQL (Kusto):** Learning the query language. Basic and advanced queries.
- **Defender XDR:** Working through defense evasion, priv escalation, lateral movement, and credential access.
- **Azure Security Challenges:** Red/blue team labs and some pentesting stuff.

## Thoughts so far

KQL is basically a whole new language and Defender has a lot of moving parts. But seeing how the logs come together and building queries to actually hunt for threats is pretty cool. It's different from physical servers but its starting to click.

## Why it matters

Most companies are on the cloud now, so knowing how to monitor and defend Azure is a pretty big skill for SOC work.
